## 1. Project Overview

As part of my first week of cybersecurity internship at Networkwalks, I was assigned the task of setting up a virtual laboratory environment for practical cybersecurity exercises.

The project involved installing Kali Linux on Oracle VirtualBox, configuring the virtual network using NAT Network, and assigning a static IP address to the virtual machine.

The purpose of this setup was to establish a controlled testing environment where I could perform network reconnaissance and other authorized cybersecurity assessments.

This laboratory will serve as my primary working environment for upcoming practical exercises.

## 2. Project Objectives

The main objectives of this project were:

- Install Oracle VirtualBox as the virtualization platform.
- Create and configure a Kali Linux virtual machine.
- Set up a virtual network using NAT Network.
- Configure a static IP address for the Kali Linux system.
- Establish network connectivity within the virtual laboratory.
- Prepare the environment for reconnaissance and security testing.

## 4. Implementation Process

### Step 1: Installing Oracle VirtualBox

I started by installing Oracle VirtualBox on my host computer.

VirtualBox is a virtualization application that allows users to create and run multiple operating systems within a physical computer.

It provides an environment for running virtual machines without requiring additional physical hardware.

### Step 2: Installing Kali Linux

After installing VirtualBox, I created a new virtual machine and configured it to run Kali Linux.

Kali Linux is a Linux-based operating system widely used for penetration testing, digital forensics, vulnerability assessment, and cybersecurity research.

I completed the operating system installation and prepared the virtual machine for network configuration.

### Step 3: Configuring NAT Network

I proceeded to configure the virtual machine's network adapter using NAT Network.

NAT Network allows virtual machines connected to the same virtual network to communicate with one another while sharing the host computer's network connection for external access.

This configuration provides a suitable environment for conducting controlled network testing.

### Step 4: Configuring a Static IP Address

I configured a static IP address for the Kali Linux virtual machine.

A static IP address is an IP address manually assigned to a device rather than automatically assigned through DHCP.

The purpose of this configuration was to maintain a consistent IP address for the virtual machine during laboratory exercises.

The network configuration involved identifying the active network interface and applying the appropriate IP address, subnet mask, gateway, and DNS settings.

### Step 5: Preparing the Laboratory Environment

After completing the virtual machine and network configuration, I prepared the environment for upcoming cybersecurity activities.

The laboratory was organized to support network reconnaissance and other authorized security testing exercises.
